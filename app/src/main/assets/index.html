Installation / GPS

The calculator and data entry work offline after the first successful load. Browser GPS requires HTTPS and location permission. Installed as a PWA, it opens full-screen like a normal phone app.
If Android does not show an install prompt, use your browser menu → Add to Home screen / Install app.

No flight data is transmitted anywhere by this app. Everything is stored locally in the browser unless you export it yourself.
